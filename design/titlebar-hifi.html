方案 A — 分层主次 保守方案
ServDeck
1补上产品 Logo,品牌区成为整条栏的视觉锚点 2唯一主操作 = 「新建连接」(保持绿色胶囊);「新建查询」降为描边 ghost;「管理连接分组」缩短为「管理分组」+ 下拉箭头(管理动作降级) 3改动最小:只动胶囊样式与 Logo,文字菜单区不动
代价:新建查询入口从"第一眼看到"降为第二层级,高频用户需适应;三个按钮仍占约 300px 宽度。
方案 B — IDEA 式 Ghost 工具条 推荐
1全部动作统一为「图标 + 文字」的 ghost 按钮:静态时只有文字与图标,悬停才浮现背景 — 这正是 IDEA 主工具栏的做法,信息密度高而不吵 2细分隔线分组:品牌 | 创建动作(查询/连接/分组)| 工具(工作流/SQL/驱动),扫读节奏清晰 3「关于」移到最右侧紧邻齿轮,与 IDEA 的帮助/设置同位;左侧让位给动作 4每个动作配 15px 线性图标,悬停背景统一 7px 圆角,与齿轮一致
代价:「新建连接」失去唯一的绿色强调;若希望保留一个强调点,可给「新建连接」图标染主题绿(悬停页内未做,落地时一行 CSS)。

方案 C — 品牌分区 个性方案
ServDeck
1品牌独占一个浅灰分区(渐变底 + 右分隔线),像 JetBrains 产品头的"产品铭牌",品牌感最强 2动作区维持 A 的分层胶囊;分区底色天然把品牌与动作隔开,不需要额外分隔线 3关于保持现状位置(文字菜单末位)
代价:品牌分区占用约 130px 宽度,小窗口下动作空间被压缩;分区底色与胶囊底色并存,层数略多。
统一规格(三方案通用)
·栏高 48px;品牌图标 24px / 圆角 6;品牌字 15px / 700 / 字距 -0.01em ·动作按钮高 32px(上下留 8px 呼吸),圆角 7-8px;ghost 悬停底 = 主色 8% 透明度 ·文字菜单 13px / #475467,悬停 #f2f4f7 圆角 6;分隔线 1×20px / 12% 黑 ·窗口三键维持 48 宽全高方块 + 14px 字形;齿轮 30×30 圆角 7(与三键刻意区分)
