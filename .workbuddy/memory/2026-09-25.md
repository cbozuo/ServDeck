## 窗口 resize 闪烁成因诊断（23:05，只读排查，未改任何代码）

## resize 闪烁第二轮：真正的根因是窗口类背景擦除（23:36 - 23:50）

32ms debounce 实测无效（用户反馈「内容还在抖」）。回头翻 Wails 的窗口类注册，找到教科书级配方：

`wails v2.15 internal/frontend/desktop/windows/winc/utils.go:87,90`

```go
wc.Style = w32.CS_HREDRAW | w32.CS_VREDRAW
wc.Background = w32.COLOR_BTNFACE + 1   // 非 NULL 画刷
```

`CS_HREDRAW|CS_VREDRAW` 让每次尺寸变化强制整个客户区失效，`wc.Background` 非 NULL 使 DefWindowProc 在 WM_PAINT 前先用 COLOR_BTNFACE 刷一遍整个客户区，然后才合成 WebView2。深色 UI 上一阵阵浅灰闪就来自这里，**与 WebView2 controller bounds 是否同步无关**，所以 debounce 治不了。

修复：新增 `internal/app/window_repaint_windows.go`（+ `window_repaint_other.go` stub），导出 `App.HardenWindowRepaint()`，`main.go` 在 `startupGate.bindShow` 的 Windows 分支、首帧显示之前调用。三步：
1. `SetClassLongPtr(GCL_STYLE, style & ^(CS_HREDRAW|CS_VREDRAW))`
2. `SetClassLongPtr(GCL_HBRBACKGROUND, 0)`（NULL 画刷 → DefWindowProc 不擦背景）
3. `SetWindowLongPtr(GWL_STYLE, style | WS_CLIPCHILDREN)`（父窗口绘制不覆盖 WebView2 子窗口区域）+ `InvalidateRect` 重画一次

hwnd 通过既有反射链拿到：`resolveWailsFrontendValue` → `accessibleWailsFrontendField(frontendValue, "mainWindow")` → `MethodByName("Handle").Call(nil)`（复用 `window_zoom_windows.go` 的辅助函数）。直接调而不过 `mainWindow.Invoke`，SetWindowLongPtr/SetClassLongPtr 本身线程无关，避免死锁窗口线程。

坑：
- Go 里 `uintptr(-16)` 是常量表达式，**编译报 overflow**。GWL_*/GCL_* 必须存成 `var`（运行时变量）再转 uintptr。
- 非 Windows 平台也要提供同名 `App.HardenWindowRepaint()` stub，否则 `main.go` 里那段（运行时 GOOS 判断，非 build tag）在 darwin 下编译不过。
- 同包不要重复定义 user32 LazyDLL。

## 第三轮：WS_EX_COMPOSITED + 环境变量二分开关（23:52 - 23:59）

去掉 CS_*/背景画刷仍抖。补上漏掉的那段，`WS_EX_COMPOSITED`（0x02000000，GWL_EXSTYLE=-20）：让系统把所有子窗口绘制排序到同一张离屏表面，父窗口与 WebView2 在同一个垂直同步点提交，专治这种「宿主 + 子 HWND」的撕裂。Wails 的 winc 没有设这个样式。

`internal/app/window_repaint_windows.go` 三个手法改成可单独开关，避免继续盲猜：

| env token | 动作 | API |
|---|---|---|
| `clsstyle` | 去 `CS_HREDRAW\|CS_VREDRAW` + 画刷置 NULL | `SetClassLongPtr(GCL_STYLE/-26)`、`SetClassLongPtr(GCL_HBRBACKGROUND/-10, 0)` |
| `clip` | `WS_CLIPCHILDREN` | `SetWindowLongPtr(GWL_STYLE/-16)` |
| `composited` | `WS_EX_COMPOSITED` | `SetWindowLongPtr(GWL_EXSTYLE/-20)` |
| `off`/`none` | 全部不做 | |
| 空 / `all` | 全部做（默认） | |
