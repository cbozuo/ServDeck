布局与样式规格（开发对齐用）

主题颜色全部 --gn-* token（命名与 v2-theme.css 一致），弹窗只依赖语义 token，内置浅/深 + 自定义主题均自动跟随；右上角可切换 4 种组合预览（自定义 = body[data-custom-theme] 叠加用户 CSS，仅覆盖 accent 家族）。唯一缺省的是弹窗遮罩 --gn-overlay，建议沉淀进 v2-theme.css（浅 rgba(15,23,42,.36) / 深 rgba(0,0,0,.55)）
弹窗容器宽 600px 圆角 14px，投影 --gn-shadow-lg + --gn-shadow-card；顶部距遮罩区 44px 居中
头部图标位 36px 圆角 10px（accent-soft 底 + accent-2 前景）；标题 15.5px/700；副文案 12px/1.5，fg-4，关键词 fg-2 加重
JDK 行内边距 10px 12px，圆角 10px，行距 8px；版本徽标 30px（17→accent-soft/accent-2，8→warn-soft/warn）；架构徽标 bg-active；路径 mono 10.5px 省略 + 悬停复制钮
选中态0 0 0 1.5px var(--gn-accent) 描边 + accent 4% 混底；radio 填充 accent、圆点用 --gn-on-accent（深色下自动换深色点，满足对比度）；右侧「当前使用」胶囊同 svc-badge.run 语义
选择互斥规则列表项与手动输入为同一单选组：手动路径校验通过 → 列表行清空 radio 并降权（opacity .72，悬停回满，仍可点回），选中态转移到手动框（accent 1.5px 描边 + 4% 弱底 + 左侧 radio 填充 --gn-on-accent 圆点，与列表行同一语言）；点 清除 恢复列表可选。手动校验失败时不抢选中态，列表保持原选择
手动指定「或」分隔线降级为弱分隔；输入框高 34px mono、底 --gn-bg-input，选中后改 --gn-bg-panel 混 accent 4%；校验通过行替换灰提示：accent-2 勾 + 版本信息 + 版本胶囊；失败态见状态卡二
底栏13px 18px，--gn-bg-panel-2 + 上边框 br-1；左侧快捷键提示，右侧唯一主按钮（accent-strong 底 + --gn-ant-on-primary 前景）；未选中/校验失败时置灰
