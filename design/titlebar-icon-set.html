01 本次修正

  • 去掉竖线：品牌后那条 1×16 分隔线，以及主操作区右侧的 .gonavi-titlebar-primary-actions::after，两条都删。图标组与文字组本身就是两种形态，线是重复的第二重信号。
  • 原先想给管理分组的层级树作废：它与现有「数据工作流」完全同形，两个点线状图标并排会直接糊在一起。
  • 管理分组保持文件夹不动：这是用户已经学会的映射，删掉它等于让人重新学一遍，不划算。
  • 数据目录改走盘片：文件夹被管理分组占着，数据目录需要一个能被瞬间认出来的形。圆形是全条标题栏里唯一没被用过的轮廓。

规范明细
  • 画布 24×24，活动区 2→22（20×20），图形落在 3→21 安全区；描边 1.5，端点与连接圆角
  • 图标实机 16px，与现有 PlusOutlined 等同重
  • 图标按钮 32×32、圆角 7px；命中区 32 ≥ WCAG 2.2 的 24 下限
  • 组内 2px，组间 14px，不再使用任何分隔线
  • 颜色全走 Token：--gn-fg-3 → hover --gn-fg-1，不写死色值
  • 三个按钮统一走 .gonavi-titlebar-primary-action，不再单独用系统动作样式
浮层（隐藏名称的补偿）
  • 位置 bottom，箭头朝上，与按钮同轴
  • 延迟 mouseEnterDelay: 0.35，比现有 0.75 更快
  • 键盘聚焦同样唤出；aria-label 必填
  • 文案 12.5px / 500，内边距 7px 11px，圆角 7px
  • 浅色底白 + 阴影，暗色底 #2c3138，跟随 antd 主题变量
  • 无分隔线后，浮层是唯一能说明「这一排是什么」的出口，延迟不宜再加大

07 图标变体

管理分组给两个方向，数据目录给两个方向。点按钮整页同步切换，直接报字母即可。

图标分配
新增服务（两案相同）方块 + 对角线加号
管理分组方案一 · 文件夹沿用，用户已经学会的映射不打断
数据目录方案一 · 盘片：全条唯一圆形剪影，离 5 米也认得出
方案一 不动现有图标
  • 管理分组 = 文件夹（保持现状）
  • 数据目录 = 盘片（外环 + 内环）
  • 优点：零重新学习，整条标题栏三枚新图标全部有足够墨量，16px 下一眼可辨
  • 代价：「数据目录」用盘片是借位表达，语义比文件夹松半格，靠浮层补齐
方案二 数据目录拿文件夹
  • 管理分组 = 层叠（菱形 + 底斜线）
  • 数据目录 = 文件夹
  • 优点：数据目录拿到语义最准的一版；层叠是全条唯一的斜向剪影
  • 代价：管理分组要重新学；层叠在 16px 下墨量最轻，和旁边的方块、文件夹比会显薄

08 实现要点

  • 删两条分隔线：App.tsx 里的 <div className="gonavi-titlebar-brand-divider">，以及 App.css 中 .gonavi-titlebar-primary-actions::after 那条 right: -10px 的伪元素。
  • 同步改测试：TitleBarPrimaryActions.test.tsx 有 expect(appSource).toContain('gonavi-titlebar-brand-divider')，删元素必须同时改这行断言，否则直接红。
  • 修新增服务按钮的样式失配：TitleBarPrimaryActions.tsx 用的是原生 <button className="gn-v2-titlebar-system-action">，而 App.css 的选择器是 .gn-v2-titlebar-system-action.ant-btn，必须带 antd 的 .ant-btn 才命中。原生按钮拿不到任何样式，于是渲染成默认按钮的灰底加边框，现状截图里那颗看着像被选中的就是它。
  • 建议的修法：这颗按钮改用与另两个同源的 gonavi-titlebar-primary-action，三枚图标按钮统一类名、统一 hover 与聚焦环，不再维护第二套系统动作样式。
  • 图标落位：新增服务与数据目录两枚自定义 SVG 放 components/titlebarIcons.tsx，路径写成常量便于单测断言；管理分组继续用现有的 FolderOutlined，不动。文案复用 service.modal.entry、connection.sidebar.management.title、app.tools.entry.data_root.title。
  • 窄屏：max-width: 420px 分支里那条 width: auto !important 只该作用于文字按钮，图标按钮要补 width: var(--gn-titlebar-action-height) !important，否则会被压成细条。
  • 间距：.gonavi-titlebar-leading 的 gap 建议设为 14px，组内间隔由按钮自身的 margin-left: 2px 承担。
