与 servy CLI 的对应关系

引擎外置 servy-10.1.exe，Servy.CLI 10.1.0，不打包进 exe。侧栏底部常驻引擎状态指示。
命令集install / uninstall / start / stop / restart / status / export / import。生命周期命令只吃 -n 与 -q。
必填只有 --name 与 --path 两个，其余都有默认值，弹窗其余字段全部可留空。
状态status 返回 9 态：NotInstalled、Stopped、StartPending、StopPending、Running、ContinuePending、PausePending、Paused、Unknown。卡片徽标直接映射。
安全约束
  • --params、--envVars、--password 会暴露在进程列表，UI 引导改用 SERVY_* 环境变量
  • 非 Local System 账号必须给 %ProgramData%\Servy 授 Modify 并跑 Set-ServyExePermissions.ps1
模板差异
  • Java：%JAVA_HOME%\bin\java.exe + -jar
  • Nginx：nginx.exe + -p <prefix> -c conf\nginx.conf
  • Redis：redis-server.exe redis.windows.conf
  • RustFS：rustfs.exe --data-dir <dir> --addr :9000
  • MySQL：mysqld.exe --defaults-file=<my.ini>
